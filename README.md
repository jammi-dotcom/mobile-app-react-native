# Mobile App React Native
====================================

## Description
------------

Mobile App React Native is a cross-platform mobile application built using React Native framework. This project aims to provide a seamless and native-like experience for users across both Android and iOS platforms.

## Features
------------

### Core Features

*   **Login and Registration**: Users can create an account or login to access the application.
*   **Dashboard**: A comprehensive dashboard providing users with a list of their tasks, friends, and notifications.
*   **Messaging**: Users can send and receive messages with their friends.
*   **Friend Management**: Users can add, remove, and block friends.

### Additional Features

*   **Profile Management**: Users can update their profile information and change their profile picture.
*   **Task Management**: Users can create, edit, and delete tasks.
*   **Notification System**: Users receive notifications for new messages, friend requests, and task updates.

## Technologies Used
-------------------

### Frontend

*   **React Native**: For building the user interface and user experience.
*   **JavaScript**: For scripting the application's functionality.
*   **ES6+**: For taking advantage of modern JavaScript features.

### Backend

*   **Node.js**: For creating the server-side API.
*   **Express.js**: For building the server and handling HTTP requests.
*   **MongoDB**: For storing and managing data.

## Installation
------------

### Prerequisites

*   **Node.js**: Installed on the development machine.
*   **npm**: Installed on the development machine.
*   **React Native CLI**: Installed on the development machine.

### Installation Steps

1.  Clone the repository using `git clone <repository-url>`.
2.  Navigate into the project directory using `cd mobile-app-react-native`.
3.  Install the required dependencies using `npm install`.
4.  Link the React Native modules using `npm run react-native link`.
5.  Start the application using `npm start`.

### Running the Application

To run the application on an emulator or physical device, follow these steps:

1.  Create a new emulator or connect a physical device to the development machine.
2.  Run `npx react-native run-android` or `npx react-native run-ios` depending on the target platform.
3.  The application will be launched on the emulator or device.
